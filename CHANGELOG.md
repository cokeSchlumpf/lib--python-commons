## [1.1.0](https://github.com/cokeSchlumpf/lib--python-commons/compare/v1.0.0...v1.1.0) (2026-11-01)

### Highlights

IDs created by commons now use time-ordered UUIDv7 strings via a new public function, new_id(), so primary keys are appended to indexes and carry their creation time. There are no schema or data changes and existing IDs remain valid, but UUIDv7 has fewer random bits so treat IDs-as-secrets with caution before upgrading.

## [0.2.1](https://github.com/cokeSchlumpf/lib--python-commons/compare/v0.2.0...v0.2.1) (2026-10-25)

### Highlights

LoginTokenService gains request_id_for_link(link_token), which returns the request id a login link belongs to without redeeming the link. This lets web apps auto-login when the requesting browser opens the link while keeping single-use links safe from mail scanners; the lookup is read-only and returns None for unknown, redeemed, or expired links.

## [0.1.1](https://github.com/cokeSchlumpf/lib--python-commons/compare/v0.1.0...v0.1.1) (2026-09-26)

### Highlights

This release adds a MkDocs-based documentation site (MkDocs Material + mkdocstrings) with an autogenerated API reference and a GitHub Actions workflow to deploy it to GitHub Pages. The Check workflow now builds docs with --strict to catch broken references early, and convenient Poe tasks are included for local serving and building. A small package-init fix makes the datastructures module resolvable by mkdocstrings.

### Documentation

* Add MkDocs documentation page published to GitHub Pages — site built with MkDocs Material + mkdocstrings (API reference generated from existing docstrings, one page per module; includes type signatures, source links, search and a light/dark theme). Adds a `.github/workflows/docs.yml` workflow to build and deploy to GitHub Pages on pushes to `main` (and runnable manually), builds the docs with `--strict` in the existing Check workflow, adds Poe tasks (`poe docs`, `poe docs-build`) and gitignores the built `site/`, adds an empty `src/commons/datastructures/__init__.py` so mkdocstrings can resolve the package, and adds a docs link to the README.
